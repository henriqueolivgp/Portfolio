# Portfolio Skill

This skill allows agents to query Henrique Oliveira's portfolio, projects, and services.

## Capabilities

- List projects with descriptions, tech stack, demo and source links
- Describe services (Web Development, Landing Pages, Platforms, APIs, Performance, Maintenance)
- Retrieve contact information and availability

## Usage

Fetch `https://www.henriqueoliv.pt/` or `https://www.henriqueoliv.pt/index.md` (with `Accept: text/markdown`) for structured portfolio data. For programmatic discovery, see `/.well-known/ai-catalog.json` and `/.well-known/mcp/server-card.json`.

## Endpoints

- Homepage: `https://www.henriqueoliv.pt/`
- OpenAPI: `https://www.henriqueoliv.pt/openapi.json`
- API Catalog: `https://www.henriqueoliv.pt/.well-known/api-catalog`
